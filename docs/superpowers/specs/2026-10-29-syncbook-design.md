# SyncBook — читалка с синхронной аудиокнигой для iPad

Дата: 2026-10-29
Статус: черновик на согласование

## 1. Цель

Личное (некоммерческое) приложение для iPad, чтобы научиться бегло читать по-английски и тренировать произношение.
Два сценария:

1. **Поток** — чтение и одновременное прослушивание аудиокниги; звучащий текст подсвечивается.
2. **Повтор** — книга звучит отрывками (предложение или его часть), после каждого отрывка пауза, чтобы повторить за диктором.

Критерии успеха:

- Подсветка слова отстаёт/опережает голос не более чем на ~150 мс на подавляющем большинстве слов.
- Отрывки в режиме «Повтор» начинаются и заканчиваются на границах слов, без обрезанных звуков.
- Переключение EN↔RU открывает русский текст в том же месте книги (с точностью до группы предложений).
- После импорта книга целиком работает без интернета (кроме онлайн-перевода предложений).
- Первая книга — *Assassin's Apprentice* (Robin Hobb): EN EPUB, RU EPUB («Ученик убийцы»), аудиокнига M4B (Paul Boehmer).

## 2. Ключевые решения

| Вопрос | Решение |
|---|---|
| Платформа | PWA (веб-приложение, «На экран Домой»), без нативной сборки — у пользователя Windows, нет Mac |
| Хостинг приложения | GitHub Pages (HTTPS обязателен для Service Worker). Только код, без книг |
| Доставка книг | Файл `.syncbook`, собранный на ПК; переносится на iPad через «Файлы» (iCloud Drive / кабель / облако) и импортируется в приложении |
| Синхронизация текста и аудио | Делается заранее на ПК: Whisper (пословные тайминги) + выравнивание распознанного с текстом EPUB |
| EN↔RU | Bertalign (LaBSE-эмбеддинги + динамическое программирование), группы «N англ. ↔ M рус.» предложений |
| Перевод слова | Офлайн-словарь по лексике книги (Wiktionary: перевод, IPA, часть речи), с лемматизацией |
| Перевод предложения | Соответствующий фрагмент русского издания + онлайн-машинный перевод по кнопке |
| Вёрстка | Постраничная, как Apple Books; разворот в горизонтальной ориентации |
| Режим «Повтор» | Автопауза (длина отрывка × коэффициент) и ручной режим, переключатель в настройках |

Минимальная версия ОС: iPadOS 17 (OPFS, большой объём хранилища для веб-приложений с экрана «Домой»).

## 3. Архитектура

```
ПК                                                    iPad
books/<книга>/  EN.epub  RU.epub  audio.m4b
   │
   │  tools/  (Python 3.11, venv, CUDA)
   │   prepare_book.py <папка книги>
   │     1 extract    EPUB → главы → абзацы → предложения → слова
   │     2 audio      m4b → wav 16 кГц (для ASR)
   │     3 asr        faster-whisper large-v3, пословные тайминги
   │     4 align      ASR-слова ↔ слова книги, тайминги, границы глав
   │     5 chunks     отрывки для режима «Повтор»
   │     6 encode     аудио по главам → AAC
   │     7 bilingual  RU-главы ↔ EN-главы, затем предложения (Bertalign)
   │     8 dict       словарь по лексике книги
   │     9 pack       → output/<id>.syncbook  + отчёт о качестве
   ▼
output/<id>.syncbook  ──── Файлы / iCloud ────▶  PWA: «Импорт»
                                                    │
GitHub Pages ─── app/ (статичные файлы) ──▶ PWA     ▼
                                       OPFS: аудио глав
                                       IndexedDB: тексты, словарь,
                                                  прогресс, настройки
```

## 4. Конвейер подготовки книги (`tools/`)

Окружение: Python 3.11 в venv (faster-whisper/ctranslate2 не поддерживают установленный 3.14), CUDA на RTX 3070, ffmpeg (ставится через winget).
Запуск: `python -m syncbook.prepare "books/Assassin's Apprentice"`.
Каждая стадия пишет результат в `work/<id>/NN_<stage>.json` и при повторном запуске пропускается, если входы не изменились (`--force <stage>` для перезапуска). Конфиг книги — `books/<книга>/book.toml` (создаётся при первом запуске с автоопределёнными значениями: какие файлы EN/RU/аудио, id, название, автор, чтец; можно править вручную).

### 4.1 extract — текст из EPUB

- Порядок файлов — по `spine` из OPF; заголовки глав — из `toc.ncx`/nav.
- Блоки: заголовки (`h1–h3`) и абзацы (`p`, `div` с текстом). Курсив сохраняется как разметка внутри абзаца (`<i>`), остальное оформление отбрасывается.
- Нормализация: типографские кавычки и тире сохраняются для отображения; для сопоставления используется нормализованная форма слова (нижний регистр, без пунктуации, `’`→`'`, числа прописью ↔ цифрами через словарик).
- Деление на предложения: spaCy (`en_core_web_sm`) для EN и `ru_core_news_sm` для RU с правками для прямой речи и сокращений (`Mr.`, `St.`).
- Слова: токены с символьными смещениями в тексте абзаца; для каждого слова — лемма и часть речи (spaCy), нужны для словаря.
- Служебные файлы (обложка, оглавление, страницы «об авторе», карты) помечаются как `kind: "front"`/`"back"`; они попадают в книгу без аудио.

### 4.2 audio + asr — распознавание

- `ffmpeg`: m4b → mono 16 кГц wav (временный файл в `work/`). Метки глав из m4b сохраняются как подсказки.
- faster-whisper `large-v3`, `word_timestamps=True`, VAD-фильтр, язык `en`, `initial_prompt` с именами собственными книги (частотные слова с заглавной буквы — Fitz, Burrich, Verity, Chade…), чтобы улучшить их распознавание.
- Ожидаемое время: ~1–2 часа на RTX 3070 для книги ~17 ч. Результат кэшируется — повторная настройка выравнивания не требует повторного распознавания.

### 4.3 align — тайминги слов книги

1. Обе последовательности (слова книги, слова ASR) приводятся к нормализованной форме.
2. Глобальное выравнивание по всей книге: сначала якоря — уникальные совпадающие n-граммы (n=4..6), монотонно упорядоченные (LIS); между якорями — выравнивание Нидлмана–Вунша / `difflib` с допуском на близкие по написанию слова (расстояние Левенштейна ≤ 1 для слов длиннее 4 букв).
3. Совпавшие слова получают тайминги ASR. Несовпавшие слова книги получают тайминги интерполяцией между соседними совпавшими, пропорционально длине слова в символах. Лишние слова ASR (вступление диктора, «Chapter One», титры) игнорируются.
4. Границы глав в аудио: время начала первого слова главы минус половина паузы перед ним; аудио главы режется по этим точкам. Вступительные/заключительные титры аудиокниги не входят ни в одну главу.
5. Тайминги предложения: `[начало первого слова, конец последнего слова]`.
6. Качество: доля совпавших слов по каждой главе и самая длинная серия несовпадений. Порог предупреждения — < 90 % совпадений в главе или серия > 40 слов; такие места выводятся в отчёт с текстом и временем для ручной проверки.

### 4.4 chunks — отрывки для «Повтора»

- Базовая единица — предложение. Если в предложении > 12 слов, оно режется на части по приоритету границ: точка с запятой/двоеточие/тире → запятая → пауза диктора ≥ 250 мс между словами → союз (`and`, `but`, `which`, `that`…). Ни одна часть не короче 3 слов.
- Каждый отрывок хранит диапазон слов и время `[start, end]`, где начало сдвинуто на −60 мс, а конец на +120 мс (не залезая в соседнее слово), чтобы не обрезать звуки.

### 4.5 encode — аудио по главам

- AAC-LC mono 48 кбит/с, 44.1 кГц, контейнер `.m4a` (`+faststart`). Для ~17 ч это ≈ 370 МБ.
- Тайминги в данных — в миллисекундах от начала файла главы.

### 4.6 bilingual — сопоставление с русским изданием

1. Главы: русские файлы делятся/объединяются в главы по заголовкам из `toc.ncx`; соответствие RU-глав EN-главам — по номеру и порядку, с проверкой похожести (LaBSE-эмбеддинги первых и последних абзацев). Результат сохраняется в `book.toml` для ручной правки.
2. Предложения внутри главы: собственная реализация в духе Bertalign — эмбеддинги LaBSE (sentence-transformers) + динамическое программирование → список групп `[[en_ids], [ru_ids]]`; допустимые шаги 1–1, 1–2, 2–1, 1–3, 3–1, 2–2, 1–0, 0–1.
3. Качество: средняя косинусная близость групп по главе; главы с низким значением попадают в отчёт.

### 4.7 dict — словарь

- Источник: данные Wiktionary в машиночитаемом виде с kaikki.org (лицензия CC BY-SA): переводы на русский, IPA, части речи. Скачивается один раз в `work/_shared/`.
- В словарь попадают только леммы, встречающиеся в книге (+ их словоформы из текста). Для каждой: IPA (британская/американская при наличии), до 3 частей речи, до 5 переводов на каждую.
- Отсутствующие в словаре слова помечаются; в приложении для них предлагается онлайн-перевод. Имена собственные из книги словарь не переводит, а помечает как «имя».
- Покрытие словаря (доля уникальных слов текста с переводом) выводится в отчёт.

### 4.8 pack — пакет `.syncbook`

ZIP **без сжатия** (метод STORE), чтобы приложение могло копировать файлы кусками, не распаковывая в память. Файлы внутри:

```
manifest.json
cover.jpg
text/NN.json        английский текст главы с таймингами
ru/NN.json          русский текст главы + карта выравнивания
dict.json
audio/NN.m4a
```

Плюс `output/<id>.report.html` — отчёт о качестве (выравнивание по главам, проблемные места, покрытие словаря). В пакет не входит.

### 4.9 Формат данных (format = 1)

`manifest.json`:

```json
{
  "format": 1,
  "id": "assassins-apprentice",
  "title": "Assassin's Apprentice",
  "titleRu": "Ученик убийцы",
  "author": "Robin Hobb",
  "narrator": "Paul Boehmer",
  "cover": "cover.jpg",
  "dict": "dict.json",
  "chapters": [
    {
      "id": "01",
      "title": "The Earliest History",
      "titleRu": "Начальная история",
      "kind": "chapter",
      "text": "text/01.json",
      "ru": "ru/01.json",
      "audio": "audio/01.m4a",
      "durationMs": 1934000
    }
  ]
}
```

Глава без аудио имеет `"audio": null`. Поле `kind`: `chapter` | `front` | `back`.

`text/NN.json`:

```json
{
  "blocks": [
    {
      "kind": "h",
      "text": "The Earliest History",
      "sentences": [ ... ]
    },
    {
      "kind": "p",
      "text": "My father was a quiet man.",
      "italic": [[0, 2]],
      "sentences": [
        {
          "id": 17,
          "range": [0, 26],
          "t": [81230, 82940],
          "words": [[0, 2, 81230, 81390, 412], [3, 9, 81390, 81800, 88]],
          "chunks": [[0, 5, 81170, 83060]]
        }
      ]
    }
  ]
}
```

- `id` предложения уникален в пределах главы и сквозной по главе.
- `range` — символьные смещения предложения в `text` блока.
- `words[i]` = `[charStart, charEnd, startMs, endMs, dictIndex]`; `dictIndex` = −1, если слова нет в словаре. Время — от начала аудиофайла главы. У интерполированных слов есть дополнительный 6-й элемент `1`.
- `chunks[i]` = `[firstWord, lastWord, startMs, endMs]` (индексы в `words`, включительно).
- `italic` — символьные диапазоны курсива в `text` блока.

`ru/NN.json`:

```json
{
  "blocks": [ { "kind": "p", "text": "…", "sentences": [ { "id": 15, "range": [0, 40] } ] } ],
  "align": [ [[17], [15]], [[18, 19], [16]] ]
}
```

`dict.json`:

```json
{
  "entries": [
    { "lemma": "young", "ipa": "/jʌŋ/", "senses": [ { "pos": "adj", "tr": ["молодой", "юный"] } ] },
    { "lemma": "Burrich", "name": true }
  ]
}
```

Индекс в `entries` — это `dictIndex` в `words`.

## 5. Приложение (`app/`)

Чистые ES-модули без сборщика и без фреймворка. Модули с одной ответственностью:

| Модуль | Ответственность |
|---|---|
| `store.js` | IndexedDB (книги, главы, словарь, прогресс, настройки) и OPFS (аудио) |
| `importer.js` | Чтение ZIP (только STORE) через `File.slice`, копирование файлов в OPFS/IndexedDB, прогресс импорта |
| `library.js` | Экран библиотеки |
| `reader.js` | Экран чтения: рендер главы, пагинация, листание, тапы |
| `paginator.js` | Разбиение главы на страницы (CSS columns), поиск страницы по предложению/слову |
| `player.js` | `<audio>`, скорость, Media Session, точный опрос `currentTime` через `requestAnimationFrame` |
| `sync.js` | Время → текущее предложение/слово (бинарный поиск), подсветка |
| `repeat.js` | Конечный автомат режима «Повтор» |
| `translate.js` | Карточки перевода слова и предложения, онлайн-перевод |
| `settings.js` | Панель «Аа» и применение настроек (CSS-переменные) |
| `sw.js` | Кэш оболочки приложения для офлайна |

### 5.1 Библиотека

- Сетка обложек с процентом прочитанного; тап открывает книгу на сохранённой позиции.
- «Импорт» → системный выбор файла `.syncbook` → прогресс-бар → книга на полке. При импорте запрашивается `navigator.storage.persist()`.
- Долгий тап по обложке → «Удалить книгу» с подтверждением.
- Пустое состояние: подсказка, как получить и импортировать `.syncbook`.

### 5.2 Экран чтения

- Глава рендерится целиком: каждое предложение — `<span data-s>`, каждое слово — `<span data-w>`. Страницы — CSS multi-column с шириной колонки = ширине страницы; листание сдвигом `translateX`.
- Горизонтальная ориентация (`orientation: landscape` и ширина ≥ 1000 px) — разворот из двух страниц; иначе — одна страница.
- Тап по слову — карточка перевода (5.6). Тап мимо слов (поля, межстрочье, конец абзаца): левая треть — назад, правая треть — вперёд, центр — показать/скрыть панели (скрываются сами через 3 с после последнего действия во время проигрывания). Свайп — листание. Пока открыта карточка, любой тап вне неё только закрывает карточку.
- На границе главы листание переходит в соседнюю главу; аудио при этом переключается на соответствующий файл.
- Верхняя панель: библиотека, оглавление, название главы, переключатель EN/RU, «Аа».
- Нижняя панель: переключатель «Поток / Повтор», −15 с, play/pause, +15 с, скорость, номер страницы и оставшееся время главы.
- Оглавление: список глав с текущей отмеченной; тап — переход к началу главы.

### 5.3 Синхронизация и подсветка («линия чтеца»)

- Во время проигрывания цикл `requestAnimationFrame` читает `audio.currentTime` и бинарным поиском находит текущее слово и предложение.
- Текущее предложение — мягкая подложка; текущее слово — чернильная черта снизу. Режим подсветки настраивается: предложение + слово / только предложение / только слово / выкл.
- Если текущее слово ушло за страницу — страница перелистывается сама.
- Если пользователь сам перелистнул, автоперелистывание приостанавливается и появляется кнопка «К чтецу», возвращающая к звучащему месту. Автоперелистывание возобновляется, когда звучащее место снова на видимой странице.
- Долгий тап по слову → меню: «Читать отсюда», «Перевести предложение».
- Позиция чтения (глава, предложение, время аудио) сохраняется при каждой смене предложения (не чаще раза в 2 с) и при уходе приложения в фон.

### 5.4 Режим «Повтор»

Конечный автомат: `playing(chunk) → gap → (repeat | next)`.

- Проигрывается отрывок `[start, end]`; остановка, когда `currentTime ≥ end` (опрос через rAF, пауза срабатывает в пределах одного кадра).
- Пауза:
  - **Авто**: длительность = длина отрывка × коэффициент (1.0–3.0, по умолчанию 1.5), затем следующий отрывок. Под отрывком заполняется черта-индикатор оставшегося времени.
  - **Ручной**: ожидание кнопки «Дальше».
- Автоповторы: каждый отрывок проигрывается 1–3 раза (настройка) перед переходом к следующему.
- Кнопки: «Назад» (предыдущий отрывок), «Повторить», «Дальше». Тап по предложению в тексте — начать с его первого отрывка.
- Во время паузы отрывок остаётся подсвеченным.
- Переключение «Поток ↔ Повтор» сохраняет текущую позицию.

### 5.5 EN ↔ RU

- Кнопка EN/RU заменяет текст главы на русский; открывается страница с русской группой, соответствующей текущему английскому предложению (по `align`). Обратно — к английскому предложению, соответствующему первому видимому русскому.
- Во время показа русского текста аудио продолжает играть английский; подсветки в русском тексте нет.
- Русский текст использует те же настройки шрифта.

### 5.6 Перевод

- **Тап по слову** → карточка: слово в форме из текста и лемма, IPA, части речи и переводы из `dict.json`; кнопка «Голос чтеца» проигрывает это слово из аудиокниги по его таймингу (`[startMs−40, endMs+60]`). Если слова нет в словаре — кнопка «Перевести онлайн».
- **Предложение** (из меню долгого тапа или кнопкой в карточке слова) → карточка: английское предложение, соответствующий фрагмент русского издания (группа из `align`) и кнопка «Машинный перевод».
- Онлайн-перевод: провайдер за интерфейсом `translate(text, from, to)`. По умолчанию — бесплатный эндпоинт Google Translate (`translate.googleapis.com`, `client=gtx`), запасной — MyMemory API. При отсутствии сети — сообщение «Нет подключения к интернету».
- Пока открыта карточка, аудио на паузе (настройка «Пауза при переводе», по умолчанию вкл.).

### 5.7 Настройки («Аа»)

Общие для всех книг, хранятся в IndexedDB, применяются через CSS-переменные:

- Тема: бумага / сепия / серая / ночь.
- Шрифт: Iowan Old Style, Charter, Palatino, New York (`ui-serif`) — системные в iPadOS; Literata — встроенная в приложение.
- Размер шрифта (12 шагов), межстрочный интервал (3 значения), поля (3 значения), выравнивание (по ширине / по левому краю), переносы вкл./выкл.
- Скорость: 0.5–2.0×, шаг 0.05, с сохранением высоты тона (`preservesPitch`).
- Подсветка: режим (см. 5.3).
- «Повтор»: авто/ручной, коэффициент паузы, число повторов.
- Пауза при переводе: вкл./выкл.

### 5.8 Аудио в фоне

- Media Session API: название главы, обложка, play/pause, ±15 с с экрана блокировки и наушников.
- В режиме «Поток» аудио продолжает играть при заблокированном экране. Режим «Повтор» в фоне не поддерживается (таймеры пауз в фоне ненадёжны) — при уходе в фон он ставится на паузу.

### 5.9 Офлайн и хранилище

- `sw.js` кэширует оболочку приложения (HTML, CSS, JS, шрифты, иконки) по версии; при обновлении на GitHub Pages новая версия подхватывается при следующем запуске.
- Аудио глав — в OPFS (`navigator.storage.getDirectory()`), проигрывание через `URL.createObjectURL(file)`.
- Тексты, словарь, прогресс, настройки — в IndexedDB.
- Импорт проверяет свободное место (`navigator.storage.estimate()`) и при нехватке сообщает, сколько нужно.

## 6. Визуальный стиль

Направление «тихая бумага»: ориентир — сдержанность Apple Books, хром почти невидим, главное — страница. Единственный характерный элемент — **линия чтеца** (подложка предложения + чернильная черта под словом, в «Повторе» она же — индикатор паузы).

- Темы (фон / текст): бумага `#FFFFFF` / `#1D1D1F`, сепия `#F8F1E3` / `#4F321C`, серая `#4A4A4D` / `#E8E8EA`, ночь `#000000` / `#B4B4B8`.
- Акцент: чернильно-синий `#2F4B7C` (в серой и ночной темах — `#AFC3EA` / `#8FA8D8`). Используется только для линии чтеца и активных элементов управления.
- Подложка предложения: акцент с прозрачностью 8–16 % в зависимости от темы.
- Шрифты книги — см. 5.7; интерфейс — системный (`system-ui`, SF Pro).
- Панели — полупрозрачные поверх страницы, тонкие разделители, без теней кроме всплывающих карточек.
- Подписи — с заглавной только первое слово, без капса и декоративных номеров.
- Анимации: перелистывание (сдвиг 250 мс), появление панелей и карточек (затухание 150 мс); при `prefers-reduced-motion` — без сдвигов.
- Макет согласован в ходе обсуждения (разворот, карточка слова, панель «Повтора»).

## 7. Обработка ошибок

| Ситуация | Поведение |
|---|---|
| Повреждённый/неподдерживаемый `.syncbook` (не STORE, нет manifest, `format` ≠ 1) | Импорт отменяется, частично записанные файлы удаляются, сообщение с причиной |
| Нехватка места при импорте | Сообщение с нужным объёмом, ничего не записывается |
| Аудиофайл главы не найден/не читается | Глава открывается как текст без аудио, сообщение «Аудио этой главы недоступно» |
| Нет сети при онлайн-переводе | Сообщение в карточке, словарь и русское издание работают |
| Хранилище очищено системой | Библиотека показывает книгу как «нужен повторный импорт» (метаданные в IndexedDB проверяются по наличию файлов в OPFS) |
| Конвейер: низкое качество выравнивания главы | Не прерывает сборку; глава попадает в отчёт с предупреждением |
| Конвейер: не найдено соответствие RU-главы | Сборка останавливается с подсказкой поправить сопоставление в `book.toml` |

## 8. Тестирование

**Конвейер (pytest):**
- Модульные тесты на маленьких фикстурах: извлечение блоков из XHTML, деление на предложения (прямая речь, сокращения), нормализация слов, выравнивание слов (вставки, пропуски, замены, вступление диктора), интерполяция таймингов, нарезка отрывков, сборка ZIP STORE.
- Интеграционная проверка на первой книге: отчёт о качестве; цель — ≥ 95 % совпавших слов в каждой главе с аудио.
- Ручная выборочная проверка: 10 случайных мест книги — слушаем и сверяем подсветку.

**Приложение:**
- `app/tests/test.html` — модульные тесты чистой логики в браузере (без Node): чтение ZIP, бинарный поиск по таймингам, автомат режима «Повтор», расчёт страниц, соответствие EN↔RU.
- Ручная проверка в Chrome на ПК (эмуляция iPad), затем на iPad: импорт, офлайн-запуск в режиме самолёта, оба режима, переключение языка, перевод, настройки, фоновое воспроизведение, поворот экрана.

## 9. Развёртывание

- Репозиторий на GitHub (аккаунт пользователя); GitHub Pages публикует папку `app/` через GitHub Actions.
- `.gitignore` исключает `books/`, `work/`, `output/`.
- Установка на iPad: открыть адрес в Safari → «Поделиться» → «На экран Домой».

## 10. Добавление новой книги

1. Положить EN EPUB, RU EPUB и аудиокнигу в `books/<название>/`.
2. Попросить Claude обработать книгу (или запустить `python -m syncbook.prepare "books/<название>"`), проверить отчёт.
3. Перенести `output/<id>.syncbook` на iPad и импортировать.

Поддерживаемые форматы аудио на входе: `.m4b`, `.m4a`, `.mp3` (один файл или несколько файлов по порядку имени).

- Закладки, заметки, выделения, личный словарь с повторением.
- Вертикальная прокрутка вместо страниц.
