# SyncBook

Личная читалка для iPad: английская книга + аудиокнига с синхронной подсветкой, режим «Повтор»
для тренировки произношения, переключение на русский перевод и перевод слов по тапу.

- `app/` — веб-приложение (PWA), публикуется на GitHub Pages. Книг в нём нет.
- `tools/` — конвейер подготовки книги на ПК (Python, Whisper на GPU).
- `books/`, `work/`, `output/` — исходники книг, промежуточные данные и готовые файлы. В git не попадают.

## Добавить книгу

1. Положите в `books/<название>/` английский EPUB, русский EPUB и аудиокнигу (`.m4b`, `.m4a` или `.mp3`).
2. Соберите книгу (или попросите Claude):

   ```bash
   cd tools
   .venv/Scripts/python -m syncbook.prepare "../books/<название>"
   ```

   При первом запуске создаётся `books/<название>/book.toml` — в нём можно поправить название,
   чтеца и соответствие глав (`ru_chapter_map`), если в переводе главы объединены или разделены.
3. Откройте отчёт `output/<id>.report.html`: главы с низким процентом совпадения подсвечены.
4. Перенесите `output/<id>.syncbook` на iPad (iCloud Drive, AirDrop, кабель) и импортируйте в приложении.

Повторный запуск пропускает готовые стадии; `--force align chunks` перезапускает выбранные.

## Установка на iPad

1. Откройте адрес GitHub Pages в Safari.
2. «Поделиться» → «На экран Домой».
3. Запускайте с экрана «Домой»: так приложение работает офлайн и хранит книги.

## Проверка на iPad

- [ ] Импорт `.syncbook` из «Файлов», книга появилась на полке
- [ ] Авиарежим: приложение открывается, книга читается и звучит
- [ ] «Поток»: подсветка идёт за голосом, страницы перелистываются сами, «К чтецу» возвращает
- [ ] Экран заблокирован: звук продолжается, управление с экрана блокировки и наушников
- [ ] «Повтор»: авто-пауза, ручной режим, повторы, «Назад» / «Повторить» / «Дальше»
- [ ] EN ↔ RU в середине главы открывает то же место
- [ ] Тап по слову: перевод, «Голос чтеца»; «Предложение» показывает русский фрагмент
- [ ] Поворот экрана и смена размера шрифта сохраняют место
- [ ] Темы, шрифты, скорость сохраняются после перезапуска

## Разработка

```bash
python -m http.server 8080
```

Приложение — `http://localhost:8080/app/`, тесты — `http://localhost:8080/app/tests/test.html`
(тесты используют ту же базу, что и приложение, и удаляют тестовые книги).
Мини-книга для разработки: `tools/.venv/Scripts/python -m syncbook.fixture output/mini.syncbook`.
Тесты конвейера: `cd tools && .venv/Scripts/python -m pytest`.

После изменения файлов в `app/` увеличьте `APP_VERSION` в `app/sw.js`.
